# Salesforce Killed The Browser. Every Agent Runs Your CRM Now. — Nate Jones AI News & Strategy Daily

## Summary
The episode analyzes the current AI agent landscape, arguing that the industry has moved past the hype cycle of "model quality" (benchmarks and flashy demos) and into a critical phase focused on "infrastructure." The speaker posits that the true value of any new agent launch is not its intelligence, but its ability to connect, expand, and operate within existing enterprise systems. The core thesis is that the market is shifting from a "switching question" (e.g., "Should I use ChatGPT or Copilot?") to a "layering question" (how can these tools be embedded and stacked together?).

To cut through the noise, the speaker introduces a rigorous "Five Question Filter" used to evaluate every agent launch. This framework prioritizes tools that enhance existing workflows rather than demanding costly migrations. The analysis then applies this filter to major players—OpenAI's GPT Workspace Agents, Salesforce's Headless 360, and Microsoft's Copilot Wave 3—highlighting that while each platform excels in different areas (cross-tool workflow vs. deep data access vs. native enterprise governance), the underlying trend is the embedding of AI engines (like Anthropic's Claude) into multiple, disparate products.

## Key Points
- **The Shift from Model to Infrastructure:** The most valuable agent news is infrastructure news. The worst news is a new destination requiring migration, as SaaS history proves migration is the most expensive thing a team can do.
- **The Five Question Filter (The Core Framework):**
    1. **Plugs into Existing Tools:** Does it enhance current tools, or does it require moving work to a new environment? (Focus on enhancement, not migration.)
    2. **Open for Building:** Can other agents build on top of it (e.g., via APIs/SDKs), or is it a closed product? (Infrastructure compounds; features commoditize.)
    3. **Owns/Accesses Data:** Agent quality is downstream of data access. A mediocre agent with full customer history is better than a brilliant agent with an empty context window.
    4. **Ecosystem Formation:** Look for marketplaces, SDKs, and partner programs, as these indicate longevity and compounding value.
    5. **Stackability:** Can the agent be composed with other agents? (Composition multiplies value; addition just adds complexity.)
- **Salesforce Headless 360 (The Infrastructure Play):** Salesforce is positioning itself as the infrastructure layer for the agent economy. By exposing every major capability as an API, it allows *any* external agent (coding, workspace, etc.) to interact with live org data, bypassing the need for the browser UI.
    *   *Key Detail:* The platform is building over 60 new MCP tools and supporting tools like Cloud Code and Cursor, making it highly open.
- **Microsoft Copilot (The Data Moat):** Copilot's strength lies in its deep, native integration within the Microsoft 365 organizational graph (SharePoint, Outlook, Teams, etc.). Its moat is its ability to operate *inside* the organizational context, making it extremely powerful for native Microsoft enterprises, though it is less open to external agent frameworks than Salesforce.
- **OpenAI GPT Workspace Agents (The Workflow Unit):** This represents a shift from the "helpful personal assistant" model to a "reusable work unit" model. These agents are designed for repeatable, cross-tool business workflows (e.g., risk screening, metrics reporting) that span multiple systems (Slack, email, documents, etc.).
- **Claude/Anthropic (The Embedded Engine):** Anthropic's strategy is to become the managed infrastructure layer—the embedded engine *inside* other people's products (Salesforce, Microsoft, etc.), rather than building a standalone replacement product.

## Tools & Resources
- **Salesforce Headless 360:** The initiative to expose the entire Salesforce platform via APIs/MCP tools, making it accessible to external agents.
- **OpenAI Workspace Agents:** Shared, codex-powered agents built for repeatable, cross-tool business workflows.
- **Microsoft Copilot WorkIQ:** The data layer that gives Copilot full context access across the entire Microsoft 365 suite (email, meetings, files, identity).
- **Anthropic Claude:** Positioning itself as an embedded, managed infrastructure layer for enterprise products.
- **MCP (Managed Connectivity Protocol):** The emerging standard or layer that allows different agent frameworks to interact with a single platform (like Salesforce).

## Action Items
- [ ] **Develop a "Five Question Filter"** for evaluating any new SaaS or AI tool: Does it plug into existing systems? Is it open for other agents to build on? Does it own/access critical data? Is there an ecosystem forming? Can I stack my agents on top of it?
- [ ] **Prioritize Infrastructure Over Features:** When evaluating tech investments, favor tools that expose APIs and act as connective tissue (like Salesforce Headless 360) over standalone, closed-loop applications.
- [ ] **Audit Data Access:** Identify the single most critical data source (e.g., CRM data, internal knowledge base) and evaluate which AI tool provides the deepest, most native access to that specific data, regardless of the tool's marketing hype.
- [ ] **Focus on Workflow Automation:** Shift the focus of automation efforts from "replacing a job" to "automating a repeatable, cross-tool workflow" (e.g., using agents to triage requests that live across Slack, email, and ticketing systems).
- [ ] **Follow the "Embedded Engine" Strategy:** Monitor companies like Anthropic and Salesforce, as their strategy of becoming the foundational, embedded layer for other products signals the most durable, long-term enterprise value.
