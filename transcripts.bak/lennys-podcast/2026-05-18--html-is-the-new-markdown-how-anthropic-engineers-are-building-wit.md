# HTML is the new Markdown: How Anthropic engineers are building with Claude Code | Thariq Shihipar — Lenny's Podcast

## Summary
This episode of Lenny’s Podcast features Claire Vo, a product leader and AI obsessive, discussing a fascinating shift in how developers are interacting with AI agents, specifically Anthropic’s Claude Code. The core argument is that HTML is rapidly becoming the preferred format for communication with these agents, moving beyond the limitations of Markdown. Vo argues that as AI agents become more complex and generate longer outputs (like Opus 4.5 and 4.7 running for an hour), simply reading lengthy Markdown files is impractical. The key takeaway is that developers are increasingly becoming “compute allocators,” needing to strategically decide where to invest computational resources. Vo emphasizes the importance of understanding the agent’s output and engaging with it actively, framing this as a new skill – essentially, being a “computer” in the process. She highlights the increased readability and richer communication offered by HTML, allowing for more effective collaboration and ultimately, better outcomes.

## Key Points
- **HTML is replacing Markdown:** Claude Code and similar agents are generating longer, more complex outputs, making Markdown files unwieldy and difficult to manage.
- **The rise of “compute allocators”:** Developers are now responsible for strategically allocating compute resources based on the value of the agent’s output.  Vo uses the analogy of spending $500 on Claude’s runtime, highlighting the need for careful prioritization.
- **Rich Communication with HTML:** HTML provides a more readable and scrollable format for agents’ outputs, facilitating deeper engagement and understanding. It allows for richer visual representations and more complex information to be conveyed.
- **Active Engagement is Crucial:**  Vo stresses the importance of actively engaging with the agent’s output, rather than passively reading lengthy documents.  Understanding the agent’s reasoning and asking clarifying questions is paramount.
- **Planning Matters More Than Ever:** Despite the intelligence of AI agents, plans, PRDs, and specifications remain critical for guiding the development process.

## Tools & Resources
