# Code with Claude: The 5 biggest updates explained — Lenny's Podcast

## Key Points
- **Routines:** Claude Code now supports scheduled routines triggered by cron jobs, HTTP requests, or GitHub webhooks. This allows users to automate tasks like generating weekly newsletters based on changelogs, checking PRDs, or triggering actions based on external events.
- **Outcomes:** Anthropic’s “Outcomes” feature allows users to define a rubric (a markdown file) for an agent to follow, enabling the agent to iteratively refine its output until it meets the specified criteria. This is designed for tasks like refining PRTs or generating content based on specific guidelines. The system can iterate up to 20 times.
- **Multi-Agent Framework:** The Claude Manage Agents API now supports explicitly defining multi-agent teams with an orchestrator and delegate agents, each with their own toolsets. This enables complex workflows where agents collaborate to solve problems, exemplified by a potential PRT workflow with a strategy, critic, and review agent.
- **Dreams (Agent Memory):** A new primitive, “Dreams,” allows agents to consolidate memory from past sessions by explicitly reviewing and writing key information to disk. This is intended to improve agent performance over time, though currently in research preview.
- **Increased Usage Limits:** Starting today, Claude Code’s 5-hour limits are doubled across pro max and team plans, and rate limits for Opus models in the API are increased. This addresses a common pain point for developers and allows for more intensive experimentation.

## Tools & Resources
- **Claude Code:** Anthropic’s code generation tool.
- **Claude Manage Agents:** Anthropic’s API for managing and orchestrating AI agents.
- **Cron Jobs:** A scheduling utility for running tasks at specific times.
- **GitHub Webhooks:** A mechanism for triggering actions in other applications based on events in a GitHub repository.
- **Markdown:** A lightweight markup language used for defining the rubric in the Outcomes feature.
