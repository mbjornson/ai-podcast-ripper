# Drew Wilson - How designers become builders and the future of tooling — Dive Club

## Summary
Drew Wilson, founder of Opacity, discusses the fundamental breakdown between design and engineering workflows, arguing that the current handoff process—where a "pretty picture" from a designer becomes a complex build in code—is obsolete. His core thesis posits that the future requires a single source of truth where designers can create components on a canvas, but those components are simultaneously generating underlying, usable DOM (Document Object Model) code, rather than just being visual representations (like WebGL).

Wilson's background is highly credible for this topic: he has nearly 30 years of experience as both a designer and an engineer, complemented by 15 years in management. This deep, dual-discipline perspective allows him to pinpoint the exact pain points that exist *after* the design phase—the overwhelming dread of starting the build process—and use it as the basis for his product vision. He argues that tools like Figma, while powerful, are fundamentally flawed because they prioritize visual fidelity (WebGL) over code usability (DOM), thereby perpetuating the separation gap.

The discussion extends beyond just tooling; Wilson predicts a massive shift in professional roles. AI and advanced coding agents will not make engineers smarter, but exponentially more productive, lowering the barrier to entry for complex development. This productivity boost will necessitate a fundamental rethinking of what "senior" or "expert" means in both design and engineering fields.

## Key Points
- **The Single Source of Truth (SSOT) Mandate:** The future requires eliminating separation between design and code. Currently, tools like Figma create visual assets that are not inherently usable DOM code; they are essentially a "pretty picture." True SSOT means the canvas output *is* the underlying, functional code structure.
- **Technical Flaw in Current Tools:** Figma's use of WebGL for its canvas is cited as a major drawback because it does not build on the browser's native DOM technology, making the design file itself useless for direct coding without manual intervention (copy/pasting), which creates two separate sources of truth.
- **The Ideal Workflow Model:** The proposed solution involves designers working on a canvas that simultaneously generates underlying code objects. Engineers do not copy and paste; they "grab" these components as NPM packages, treating the design output like an updated library version (e.g., Version 1.2).
- **AI's Impact on Engineering Roles:** AI coding agents (like Claude Code) are predicted to make engineers significantly more productive—faster than any human—but not necessarily smarter. This means that complex development capabilities will be democratized, potentially elevating the productivity of mid-level or junior developers who previously struggled to reach "senior" status.
- **Design vs. Engineering Benchmarking:** Unlike engineering, where coding tests provide a clear benchmark for skill level, design taste remains subjective. Wilson notes this difficulty in benchmarking AI's design capability, suggesting that measuring technical proficiency is easier than measuring aesthetic quality.

## Tools & Resources

## Action Items
- [ ] **Study Web Development Fundamentals:** Deepen understanding of the Document Object Model (DOM) structure to better grasp the technical limitations of current design tools vs. true code output.
- [ ] **Explore Component Libraries/NPM Packages:** Practice thinking about UI components not as static images, but as reusable, versioned packages that can be imported and updated in a codebase.
- [ ] **Experiment with Framer Design Pages:** Utilize the tool to practice turning free-form design iterations into functional web pages to understand its current capabilities in bridging the gap between visual design and code structure.
- [ ] **Monitor AI Coding Agents (e.g., Claude Code):** Treat advanced coding agents as productivity multipliers rather than replacements for deep technical knowledge; focus on learning how to guide them effectively.
- [ ] **Reframe Career Goals:** Shift focus from "mastering a skill" (e.g., becoming a senior engineer) to "optimizing workflow efficiency," recognizing that AI will elevate the baseline capability of all practitioners.
