# Escha Vera - Designing Perplexity’s Comet and Using AI Like an Artist — Dive Club

## Summary
Esha Vera details her journey designing Perplexity’s new AI browser, Comet, providing deep insights into modern product development at the intersection of advanced AI and UX design. Her background highlights a period of career uncertainty after leaving Descript, requiring extensive networking with CEOs before landing a role where she could tackle complex, high-impact problems in the rapidly evolving AI space.

The core discussion revolves around establishing a functional design system for a massive, bleeding-edge product that lacked foundational structure. Esha’s primary challenge was bridging the gap between visual design (Figma) and engineering reality (C++ code). She established a unified design system where "code is law," meaning the design tokens and components had to be implemented and enforced directly in the codebase, not just documented in Figma files.

The episode emphasizes that modern product designers are no longer merely proposal artists; they must operate with high autonomy and ownership, often being expected to contribute directly to front-end implementation alongside their design work. Furthermore, she shares a cutting-edge workflow for prototyping complex desktop user flows using Large Language Models (LLMs) like Claude or Cursor, transforming conceptual designs into functional code scaffolds.

## Key Points
- **The "Code is Law" Design System:** The most critical insight is that the design system must be enforced by the engineering layer. Instead of having a single source of truth in Figma, Perplexity's system requires one-to-one mapping: every color variable and component used in Figma must have an equivalent token/variable in the code base.
- **Atomic Component Focus:** To prevent over-architecting, focus on building core atoms (e.g., a text component nested inside a button component) rather than trying to build entire complex screens. This establishes principles for consistency while allowing flexibility at the macro level.
- **Spacing and Layout Logic:** Implement spacing rules directly into components using Auto Layout in Figma. By baking padding into components, designers eliminate guesswork regarding distance between elements (e.g., ensuring consistent divisibles of 8, 16, 24, etc.) without needing to manually calculate every margin.
- **High Autonomy = High Implementation:** The modern design role requires a shift from "proposing solutions" to "owning and implementing solutions." Designers are expected to not only define the ideal UX but also contribute code/front-end work to bring it to life, demanding proficiency in both design principles and basic engineering logic.
- **AI-Assisted Prototyping Workflow:** For complex desktop user flows (beyond simple mobile transitions), use LLMs (Claude or Cursor) by feeding them key Figma screenshots and describing the desired interaction/flow. The AI generates an initial front-end code scaffold (HTML/CSS) that is "close enough" to be quickly refined, drastically reducing the time spent on early-stage prototyping.

## Tools & Resources
- **Mobbin:** Recommended for product design inspiration, now featuring "Mobbin sites" for landing page and portfolio inspiration.
- **Framer:** Highlighted as a powerful new tool with "design pages," allowing freeform canvas exploration (including vector editing) that can be instantly converted into functional webpages without manual imports or copying/pasting.
- **Claude / Cursor:** Recommended LLMs used specifically for prototyping complex user flows and generating initial front-end code based on visual design inputs.

## Action Items
- [ ] **Develop "Code Literacy":** When designing, don't just think in pixels; think in tokens and variables. Practice defining component logic (e.g., padding rules) that can be easily translated into CSS/code structure.
- [ ] **Master Atomic Design Principles:** Focus on building reusable components based on the smallest possible units (text fields, icons, buttons). Use Figma's Auto Layout features to enforce consistent spacing and sizing principles across all mockups.
- [ ] **Implement LLM Prototyping:** Practice using Claude or Cursor by taking a complex user flow diagram/screenshot and prompting the AI to generate the corresponding HTML/CSS structure. Treat this output as a functional starting point, not a final product.
- [ ] **Audit Your Design System:** If working on a team project, advocate for establishing a single source of truth where design tokens (colors, spacing, typography) are defined *and* enforced across both the visual design file and the engineering codebase.
- [ ] **Network Strategically:** View career transitions not as waiting for an opportunity, but as actively engaging with industry leaders (CEOs/Founders) to understand their specific technical challenges in AI integration, positioning yourself as a problem solver rather than just a job seeker.
