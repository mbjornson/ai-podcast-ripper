# Emily Campbell - AI UX Deep Dive — Dive Club

## Summary
Emily Campbell, VP of Design at HackerRank, dives deep into how AI is fundamentally changing the discipline of UX design by shifting the focus from fixed interfaces to dynamic human-system communication. She argues that traditional software design involved designers guessing user needs—a process that was often inaccurate. With generative AI, users are now interacting directly with the system itself, making the designer's role less about building a static product and more about guiding the relationship between the human and the model.

The core challenge is enabling the user to effectively communicate their intent to the AI, confirming if the model understood that intent, and adapting the experience accordingly. Campbell introduces specific design patterns—Wayfinders and Tuners—that manage this complex interaction loop. She posits that successful AI experiences must facilitate a continuous process of learning and verification, moving beyond simple chat interfaces toward deep contextual understanding where the UI eventually fades away.

## Key Points
- **The Shift from Designer-in-the-Loop to Human-in-the-Loop:** The designer's primary function is no longer creating buttons or forms, but rather guiding the *experience* of communicating intent. This involves helping the user get the right context and guarding the model against misunderstanding constraints.
- **Wayfinders (Onboarding/Discovery):** These patterns are critical for initial onboarding and continuous learning. They allow users to see how others are using the AI (e.g., sample galleries showing successful prompts and results), providing a starting point and reducing cognitive load.
- **Tuners (Intent Validation):** This is a crucial pre-submission step where the user works *with* the model to confirm understanding. Instead of submitting an initial prompt, the system validates: "Okay, this is what I actually understand this action to be. Is this right?" This minimizes friction and builds trust in the AI's capability.
- **The Progression of Interaction:** Effective AI design moves through distinct stages: 1) Explicit instruction (buttons/fields); 2) Conversational context (chat interface for building shared language); 3) Implicit understanding (relying on inferred cues, like a facial expression, where the UI is almost invisible). The goal is to achieve Stage 3.
- **Redefining UX Deliverables:** Because users can now directly interact with and shape the system, Campbell notes that the traditional deliverables of a UX designer (flow charts, annotations) are becoming "hazy." Designers must adapt their focus from *what* they build to *how* they guide interaction within an evolving system.
- **Developing Taste through Sampling:** Developing true design "taste" is not just about aesthetics; it's about sampling variations—understanding why one solution works in Case A but fails in Case B (e.g., knowing if food needs salt, or a feature needs a slight adjustment).

## Tools & Resources
- **Shape of AI:** An incredible database/cataloging system for tracking and understanding various AI design patterns.
- **Framer:** Positioned as an all-in-one design tool that allows users to sketch, iterate, structure, and publish entirely within the platform (reducing the need to jump between Figma and other tools).
- **Mobbin:** A resource for viewing how world-class apps use motion and animation to guide, delight, and create seamless user experiences.

## Quotable
> "The designer is really now guiding that relationship, that experience, helping the user get the right context, the right input to the model, and then guard the model to meet the user's needs and constraints."
>
> "Developing taste... isn't just knowing that food is good. It's knowing whether or not it needs a little more salt. And the only way you can know that is if you've sampled it in all of its different variations..."

## Action Items
- [ ] **Implement Wayfinder Patterns:** When designing any AI product, dedicate space to sample galleries or "How Others Use This" sections to guide new users and demonstrate successful prompts/outcomes.
- [ ] **Design a Tuner Flow:** For any critical user input (e.g., submitting a complex prompt), build an explicit validation step where the system summarizes its understanding of the user's intent *before* executing the action, forcing mutual confirmation.
- [ ] **Practice Contextual Design:** When developing interfaces, move beyond thinking about buttons and fields. Focus on how non-verbal or implicit cues (like a change in tone or an unexpected input) can guide the AI interaction.
- [ ] **Develop a "Pattern Catalog":** Start documenting every interesting product or feature you encounter that uses novel AI interactions. Categorize them by function, not just industry, to build your own framework for understanding emerging patterns.
- [ ] **Master Framer:** If currently using Figma/Sketch, dedicate time to learning Framer's capabilities to streamline the design and publishing workflow into a single toolset.
