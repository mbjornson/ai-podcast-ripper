# Vitaly Friedman - Beyond Chat:  What's Next for AI Design Patterns — Dive Club

## Summary
The episode provides a deep dive into how Generative AI is fundamentally changing UX design patterns, arguing that the initial "magic box" excitement of tools like ChatGPT masks significant usability and interaction friction. The core thesis challenges the current obsession with complex prompt engineering, suggesting that users are too ill-equipped to articulate their intent accurately or efficiently within a simple text box interface. Instead, effective AI design must move beyond mere chat functionality toward structured, proactive workflows.

Vitaly Friedman, founder of Smashing Magazine and a long-time leader in UX thought, guides the listener through these evolving patterns. He argues that the next generation of AI interfaces should minimize the "cost of interaction"—the cognitive load required for the user to speak to the machine. The goal is not just better prompts, but designing systems where the AI anticipates needs, asks clarifying questions, and facilitates multi-step tasks using familiar UI components (like filters or buttons) rather than relying solely on free text input.

## Key Points
- **The Failure of Free Text Input:** Relying on a simple text box for complex queries creates high interaction costs because users are "very bad at articulating intent." The current model forces the user to wait, repeat information, and constantly correct the AI.
- **Shift from Prompting to Task Building:** Instead of teaching users how to write perfect prompts (a wrong approach), designers should focus on creating *Task Builders*. These patterns frame common professional tasks into structured sequences: e.g., "Search Notion for X and create a PowerPoint summary." This moves interaction from open text to click-based workflows.
- **The Value of Proactive AI:** The most powerful shift is when the AI flips roles, asking clarifying questions or guiding the user through necessary steps (e.g., "Do you want this? Do you want that?") rather than waiting for a single, perfect prompt.
- **Integrating Familiar Patterns:** Successful AI experiences are those that integrate established UI patterns—like filters, radio buttons, and sliders—into novel generative interfaces. This makes the technology feel less alien and more intuitive to the user's existing mental model.
- **Workflow Automation Examples:** Practical examples include automating cross-platform tasks (e.g., summarizing a Slack channel and exporting it directly into a Word file) or combining different data sources for output generation.

## Tools & Resources
- **Consensus:** Mentioned as an excellent example of good AI experience, demonstrating how the tool can guide users through complex search queries while still offering familiar UI elements like filters.
- **Jitter:** Tool mentioned for animating and improving video feedback loops; features include timestamped comments synced across canvas and timeline.
- **Paper (by dive.club):** A design tool highlighted as a platform enabling shaders, described as the "final frontier in UI development," allowing designers to create custom visual elements beyond standard framework limitations.

## Quotable

## Action Items
- [ ] **Design Workflow Blueprints:** Identify 3 high-frequency, multi-step tasks in your professional life (e.g., research synthesis, reporting, data extraction). Design a structured, click-based workflow for these tasks that could theoretically be automated by an LLM/AI tool, bypassing the need for long text prompts.
- [ ] **Audit Current AI Usage:** When using ChatGPT or similar tools, consciously stop writing large blocks of free text. Instead, force yourself to break down your request into a sequence of discrete steps (e.g., Step 1: Summarize X; Step 2: Identify Y; Step 3: Format as Z).
- [ ] **Explore Advanced Design Tools:** Investigate "shaders" and tools like Paper to understand how the next generation of UI design is moving beyond traditional components into highly customizable, generative visual spaces.
- [ ] **Focus on Proactive UX:** When designing or critiquing any digital product, ask: "How can this system proactively guide the user or ask clarifying questions *before* the user realizes they need to provide more information?"
