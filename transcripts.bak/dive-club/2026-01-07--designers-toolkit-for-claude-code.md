# Designer's toolkit for Claude Code — Dive Club

## Summary
The episode, featuring Kyle Zantos, focuses on the critical shift from traditional design workflows to "design engineering," where designers must actively incorporate coding and AI tools into their process. The core thesis is that the line between design and engineering is dissolving, requiring designers to develop new "design engineering muscles" to stay relevant in the current "tool explosion" era. Zantos emphasizes that the goal is not to become a full-stack developer, but to become highly proficient in rapid prototyping, tweaking, and experimenting with code and UI elements in real-time.

Zantos's background leading UX Tools Labs gives him authority on identifying which new tools and workflows genuinely matter. He guides listeners away from feeling overwhelmed by the sheer volume of new tech by promoting a philosophical approach: building a personal "workbench" of tools. The discussion highlights that the most valuable skill is the ability to treat design as a malleable, code-adjacent playground, allowing for subtle, immediate tweaks that were previously impossible without deep technical knowledge.

## Key Points
- **The Blurring of Design and Code:** The emergence of tools like Cursor with visual editors and in-app browsers signals a major shift. This allows designers to perform subtle tweaks (like adjusting padding or spacing) without needing to write complex code, keeping them out of the "prompt loop" of pure AI generation.
- **The Playground Mentality:** The most valuable approach is to "make a playground for yourself." Instead of waiting for a perfect, existing tool, build a sandbox environment (like the speaker's retro-futuristic site) to test effects, animations, and behaviors. This process of building for fun and utility is where the most practical learning happens.
- **CLI vs. GUI for Beginners:** While the true power of AI agents (like Claude Code) still resides in the terminal/CLI (e.g., Warp), designers who are starting out should utilize the friendly, extension-based UIs (like VS Code extensions). These provide a less intimidating entry point while still offering powerful functionality.
- **The "Workbench" Philosophy:** Instead of chasing the single "right setup," focus on building a personalized collection of tools and workflows. This approach allows for flexibility and continuous skill-building, rather than getting stuck trying to master one monolithic system.

## Tools & Resources
- **Cursor:** An AI-powered code editor noted for its visual editor and in-app browser, making it an accessible entry point for designers into code.
- **Warp:** A powerful terminal/CLI environment used for advanced AI coding workflows.
- **Claude Code:** The AI agent/code generation capability used for integrating design ideas into functional code.
- **Granola:** A productivity tool mentioned for its ability to synthesize and organize complex information (e.g., summarizing user research, meeting themes) from various sources.
- **Lovable:** A platform for building apps with connectors (Perplexity, 11 Labs, Miro), allowing users to build functional applications using simple natural language prompts and live web data.

## Action Items
- [ ] **Skill Development:** Practice the "playground mentality" by building a small, personal website or project that incorporates novel, self-designed interactive elements (e.g., custom hover effects, unique animations).
- [ ] **Tool Adoption:** Experiment with Cursor's visual editor and in-app browser to practice making subtle, code-level tweaks to existing UI mockups without writing full code.
- [ ] **Workflow Shift:** Dedicate time to learning basic CLI commands and integrating AI agents (like Claude Code) into a terminal environment (Warp) to move beyond the limitations of GUI-only design tools.
- [ ] **Productivity Stack:** Explore platforms like Granola or Lovable to build small, functional apps that pull live data from the web or synthesize information from multiple sources, moving beyond simple static design mockups.
