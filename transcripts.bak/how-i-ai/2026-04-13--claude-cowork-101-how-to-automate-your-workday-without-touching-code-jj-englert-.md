# Claude Cowork 101: How to automate your workday without touching code | JJ Englert (Tenex) — How I AI

## Summary
This episode features JJ Englert from 10X discussing “Claude Cowork 101,” a system for automating your workday using Anthropic’s Claude AI, specifically through their “Cowork” tool. The core concept is orchestrating multiple AI “agents” within a structured project system to handle tasks like research, content creation, and workflow management. Englert’s credibility stems from his experience as a solo founder and his early adoption and exploration of Claude’s capabilities, as evidenced by his initial Twitter article and subsequent podcast appearances. The conversation highlights the shift from relying solely on command-line interfaces and APIs to a more intuitive, button-driven approach to AI interaction, emphasizing the importance of context and personalized prompts. The episode focuses on the practical application of the tool, particularly for knowledge workers who may not have extensive technical skills.

## Key Points
- **Orchestration with Agents:** The core strategy involves using multiple AI “agents” (sub-agents) within a project system to handle complex tasks, each with a dedicated persona and context window for focused output.
- **Multi-View Feedback:**  A key benefit is the ability to simulate feedback from different stakeholders (boss, engineer, customer) within the same project, streamlining the review process.
- **Low-Code/No-Code Automation:**  Cowork simplifies AI automation by allowing users to connect existing business tools (Slack, Gmail, Notion) with a single click, eliminating the need for extensive coding.
- **Button-Driven Interface:** Englert advocates for a user-friendly, button-driven interface, arguing that many users prefer this approach over complex command-line or API interactions.
- **Project-Based Context:** The concept of “projects” – essentially folders with files – is central to the system. These projects store context, preferences, and prompts, allowing Claude to quickly understand and execute tasks without requiring constant re-prompting.
- **Workspace Map:** Claude can generate a “workspace map” to help users navigate complex projects, improving efficiency and reducing the need for Claude to ingest all the information.
- **Transferable Context:**  The ability to transfer context between projects is crucial, allowing users to reuse previously built “brains” and avoid starting from scratch each time.
