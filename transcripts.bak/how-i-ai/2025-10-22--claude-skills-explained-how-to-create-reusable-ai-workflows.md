# Claude Skills explained: How to create reusable AI workflows — How I AI

## Summary
The episode, hosted by product leader Claire Vaux, introduces "Claude Skills," a powerful new feature from Anthropic designed to solve the problem of creating dynamic, reusable AI workflows. Claude Skills are not merely prompts; they are structured, callable assets that allow a general-purpose chatbot (Claude) to execute highly specific, multi-step tasks on demand. The core discussion centers on how these skills move beyond the static context limitations of tools like OpenAI's Custom GPTs or Claude Projects, which tend to be general-purpose.

Vaux explains that a Claude Skill is essentially a structured folder containing a master prompt (`skills.md`) and associated resources. This framework allows users to define complex, repeatable professional processes—such as generating a Product Requirements Document (PRD) or performing specific data analyses—by bundling detailed instructions, templates, and even executable Python scripts. The overall message is that this feature provides a structured, engineering-grade way for non-developers to formalize and operationalize their most repetitive and valuable professional workflows using AI.

## Key Points
- **Dynamic vs. Static Context:** Unlike general AI projects (like GPTs) that load a fixed, general context, Claude Skills allow for *task-specific* instructions that can be called on demand, making the AI's output highly context-aware and targeted.
- **The Skill Structure:** A Skill is a folder containing a `skills.md` file. This file is structured with three key components:
    1. **Metadata:** A required header providing the skill's name, description, and purpose, which helps the agent decide *when* to call the skill.
    2. **Instructions:** The core prompt engineering content, detailing the steps, decision trees, and best practices for executing the task.
    3. **Resources:** Relative file links that bundle necessary context, templates, or examples (e.g., a specific PRD format).
- **Code Integration for Validation:** Skills can include executable Python scripts. This is a critical technical advantage, as it allows the user to define and validate the exact code needed for data cleaning or analysis, rather than relying on the LLM to generate variable or inconsistent code.
- **Efficiency Framework:** The skill structure provides a formal framework for product engineers and designers to document and reuse complex, multi-step workflows, eliminating the need to maintain scattered collections of prompts in Google Docs or GitHub.

## Tools & Resources
- **Claude Skills:** The core feature discussed. A structured, folder-based system for creating reusable, callable AI workflows within Anthropic's ecosystem (Claude Code, web, desktop).
- **ChatPRD:** An AI co-pilot mentioned by the host, designed to help users write product documentation, automate coordination, and provide strategic coaching from an expert AI CPO.
- **v0.dev, Google Drive, Slack, Linear, Confluence:** Examples of tools ChatPRD integrates with, highlighting the goal of accelerating AI adoption without changing existing workflows.

## Action Items
- [ ] **Develop a "Skill" Framework:** Identify 3-5 repetitive, high-value professional workflows (e.g., summarizing meeting notes into action items, drafting a competitive analysis, generating a PRD outline) that currently require manual prompt engineering.
- [ ] **Formalize the Skill Structure:** For one chosen workflow, draft the content using the Skill structure: Define the **Metadata** (Name/Purpose), write the detailed **Instructions** (the prompt logic), and gather necessary **Resources** (templates/examples).
- [ ] **Experiment with Code:** If your workflow involves data manipulation or analysis, learn how to embed a small, executable Python script within a structured prompt to ensure consistent, reliable output.
- [ ] **Explore AI Co-pilots:** Investigate tools like ChatPRD to see how they integrate AI assistance directly into existing enterprise tools (Slack, Confluence) rather than requiring a dedicated AI platform.
