# “Farm-to-table software”: How I built a Thanksgiving party hub using Lovable for managing invites, dishes, shared recipes, and photos — How I AI

## Summary
Claire Vo, a product leader and AI enthusiast, details her process of building a "Thanksgiving party hub" using a low-code prototyping tool called Lovable. The episode's core thesis is not the party hub itself, but the methodology of taking a basic, AI-generated prototype (which she calls "vibe coding slop") and elevating it to a professional, polished design. She demonstrates that true design mastery requires understanding the underlying design system—specifically typography and image parameters—and integrating specialized tools like Google Fonts and MidJourney.

The discussion also includes a segment on enterprise AI development, sponsored by WorkOS. This segment highlights a critical business challenge: while AI tools (like co-pilots and chatbots) are powerful, they face intense IT scrutiny because they require deep access to company systems. To scale, apps need robust, enterprise-grade features like secure authentication, access controls, and audit logs, which WorkOS claims to provide via drop-in APIs.

## Key Points
- **Enterprise Scalability Requires API Layers:** For AI tools to move from proof-of-concept to enterprise adoption, they must solve complex security and integration issues. WorkOS positions itself as the solution, offering "drop-in APIs for enterprise features," making it comparable to Stripe for enterprise functionality.
- **Typography is the Foundation of Design:** To "up-level" a design, focus on typography. Instead of relying on the tool's defaults, integrate specific, high-quality font combinations (e.g., Homemade Apple and Railway) sourced from Google Fonts. The key insight is that the vibe-coding tool must be able to interpret and update the underlying CSS/Tailwind framework using these external fonts.
- **Mastering AI Image Parameters (MidJourney):** Generating a usable image requires more than just a prompt. The speaker emphasizes the importance of using "style references" (long parameter codes) found on platforms like X (Twitter) to dictate a specific aesthetic (e.g., "whimsy textured storybook paint"). Furthermore, always tune the metadata, specifically the aspect ratio, to ensure the generated image fits the intended layout (e.g., changing from a square to a 2:1 header ratio).
- **Vibe Coding as a Design System Learning Tool:** The process of using tools like Lovable, Bolt, or V0 is presented not just as a way to build fast, but as a way to force the user to understand the relationship between the visual output and the underlying code (CSS/Tailwind configuration).
