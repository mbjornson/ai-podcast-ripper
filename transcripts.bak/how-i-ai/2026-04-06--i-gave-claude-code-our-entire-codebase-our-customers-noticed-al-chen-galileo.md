# I gave Claude Code our entire codebase. Our customers noticed. | Al Chen (Galileo) — How I AI

## Summary
This episode features Al Chen, Product Leader and AI Obsessive at Galileo, demonstrating how he leverages Claude Code to directly address customer technical questions related to their AI observability platform. The core idea is to bypass traditional documentation and knowledge base searches by directly querying the entire codebase with Claude Code, allowing for rapid, in-depth answers. Chen’s credibility stems from his frontline experience working with enterprise customers and his previous role at LaunchDarkly. The episode highlights a pragmatic approach to problem-solving, emphasizing the importance of contextualized information and automation. The key takeaway is that developers can use AI to accelerate their workflow and improve customer satisfaction by directly accessing and understanding the underlying code.

## Key Points
- **Direct Code Access:** Al Chen uses Claude Code to directly query Galileo’s entire codebase (15 repositories) instead of relying on public documentation or internal knowledge bases.
- **Customer-Centric Approach:** He addresses nuanced, technical questions from enterprise customers that go beyond the information provided in standard documentation. Specifically, he tackles questions about how features like caching mechanisms work.
- **Automation & Efficiency:** He’s developed a custom Claude Code command ("DPL") to automate the deployment process for customers, reducing the need for manual assistance and streamlining workflows.
- **Context is King:** The ability to traverse multiple repositories simultaneously within VS Code is crucial for providing accurate and contextualized answers. He emphasizes opening the project at the correct level for efficient querying.
- **Evolution of Codebase:**  He utilizes a script to automatically pull the latest main branches from all repositories, ensuring he’s always working with the most up-to-date code.
- **Beyond Documentation:** He argues that customers don’t want high-level documentation answers; they want step-by-step explanations of how systems work.

## Tools & Resources
- **Claude Code:** The core AI tool used for querying the codebase.
- **VS Code:** The Integrated Development Environment used for coding and accessing Claude Code.
- **Confluence & Notion:**  Tools used for storing and organizing documentation (though Al is moving beyond them).
- **Orcus:** An open-source orchestration platform mentioned as a potential solution for managing complex workflows.
- **Custom Claude Code Commands:** Al’s developed a custom command ("DPL") to automate deployment tasks.
