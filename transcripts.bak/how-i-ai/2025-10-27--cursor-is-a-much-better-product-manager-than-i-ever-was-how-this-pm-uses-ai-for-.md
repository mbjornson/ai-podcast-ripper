# “Cursor is a much better product manager than I ever was”: How this PM uses AI for PRDs, Jira tickets, and replying to coworkers | Dennis Yang (Chime) — How I AI

## Summary
The episode details how AI is fundamentally changing knowledge work, moving beyond simple code generation to become an integrated hub for complex product management workflows. Dennis Yang, a Principal Product Manager, demonstrates how to use AI-powered tools like Cursor not just for writing code, but for managing the entire lifecycle of a Product Requirements Document (PRD)—from initial drafting to publishing and gathering cross-functional feedback. The core argument is that the most valuable AI solutions are those that prioritize **interoperability**, acting as a central connective tissue between disparate enterprise tools.

The discussion highlights a critical shift in how technical concepts are applied: concepts traditionally confined to software engineering (like Markdown, Git commits, and change tracking) are now being adopted for non-code assets, such as documentation and strategic planning. This transition allows PMs to treat their content and documentation with the rigor and version control previously reserved only for code, significantly improving communication and reducing manual status update time.

## Key Points
- **Interoperability is the New Prerequisite:** The most useful AI systems are those that do not "lock away" content or data. The ability for a tool to connect seamlessly with existing enterprise systems (Jira, Notion, Confluence, Figma) is more valuable than the AI's raw intelligence alone.
- **The PM Workflow is Now Code-Like:** PMs can now use concepts like Git and change tracking for non-code assets (PRDs, documentation). This allows for structured, version-controlled collaboration that was previously difficult to manage across platforms like Confluence and Notion.
- **AI as an Orchestration Layer:** Tools like Zapier are positioned as essential for automating complex, multi-step workflows across an entire organization without requiring constant intervention from the engineering team. This enables scaling AI adoption in days, not weeks.
- **The Power of the IDE for Content:** Using an AI-powered IDE (like Cursor) as the primary interface for *all* content creation (PRDs, documentation) allows the user to maintain a single source of truth in a structured format (Markdown) while benefiting from AI assistance and cross-platform publishing capabilities.
- **Markdown is the Universal Language of Modern PM:** The emphasis on Markdown and its automatic previewing capability is a key efficiency hack. It provides a clean, structured way to write and review content that is easily portable and renderable across multiple platforms.

## Tools & Resources
- **Cursor:** An AI-powered IDE/editor that serves as a central hub for content and code. Key features include access to multiple LLMs (Claude, GPT-5, DeepSeek) and robust integration via MCPs.
- **Zapier:** An AI orchestration platform used to connect thousands of apps (e.g., connecting AI workflows to internal company processes) to automate tasks without heavy engineering lift.
- **Markdown Preview Enhanced:** A recommended extension/setting that automatically previews Markdown content, ensuring the final output looks professional and structured before publishing.
- **MCPs (Model/Content Processors):** Custom integrations built within tools like Cursor that allow the AI to interact with specific, proprietary company systems (e.g., a Jira direct MCP or a Notion MCP).
- **Atlassian Suite (Jira/Confluence):** Used as examples of enterprise systems that must be integrated into the AI workflow to ensure content is accessible and collaborative.

## Action Items
- [ ] **Adopt a "Hub" Mindset:** Stop thinking of AI tools as isolated writing assistants. Instead, view them as the central, interoperable hub that connects your existing enterprise tools (Jira, Notion, etc.).
- [ ] **Master Markdown for Documentation:** Commit to writing all strategic documents (PRDs, specs) in Markdown format. Utilize the automatic preview function to ensure clean, professional rendering, regardless of the final publishing platform.
- [ ] **Implement Workflow Automation:** Identify a repetitive, multi-step business process (e.g., "Lead intake -> Data enrichment -> Calendar check -> Draft email") and explore automating it using a platform like Zapier.
- [ ] **Explore AI IDEs:** Experiment with AI-powered IDEs like Cursor to use them as your primary text editor for *all* content, not just code. This forces you to think about content structure and version control.
- [ ] **Focus on Data Ownership:** When evaluating new SaaS tools, prioritize those that guarantee content portability and interoperability, rather than those that create proprietary data silos.
