# How to build your own AI developer tools with Claude Code | CJ Hess (Tenex) — How I AI

## Summary
The episode focuses on advanced AI engineering workflows, moving beyond simply prompting Large Language Models (LLMs) to building entire developer tool ecosystems around them. The guest, CJ Hess, emphasizes that the most powerful use of AI is not just generating code, but creating tools that make the *process* of AI engineering more efficient. He highlights Claude Code specifically for its superior "intent understanding," allowing it to pick up on subtle user intuition and enabling the construction of complex, custom workflows.

A major theme is the evolution of planning and design. CJ argues that traditional planning methods (like Markdown or ASCII flowcharts) are insufficient for modern, complex system design. He introduces his proprietary tool, Flowy, which uses structured JSON files to guide Claude Code in generating professional, iterative UI mockups and flowcharts. This approach treats the AI not just as a code generator, but as a design collaborator that can read and modify structured data, significantly raising the fidelity of the output.

## Key Points
- **Developer Tooling is the Next Frontier:** The most valuable use case for AI is building tools *for* AI engineering itself. This allows individual developers to create highly customized, efficient workflows that surpass the limitations of standard IDEs or general-purpose LLMs.
- **The Power of Structured Data (JSON):** Instead of relying on free-form text (like Markdown or ASCII diagrams), using JSON files to define system states, flowcharts, and UI elements provides a native, machine-readable structure. This allows the AI to understand the *relationships* between components, leading to vastly more accurate and usable mockups.
- **AI for Environment Setup:** Environment setup and developer onboarding is an "underappreciated use case." An AI can be prompted to handle complex, multi-step setup tasks (e.g., installing dependencies, configuring a local environment for a designer who has never used AI tools) by accepting a list of tools and executing the necessary commands.
- **Iterative Design Loop:** The workflow is designed for iteration. By having the AI read and write to a structured JSON file (which acts as the single source of truth for the design), users can edit the file like a design tool (e.g., Figma) and then point the AI back to the updated file, ensuring the model is always working from the latest, most accurate state.
- **Model Comparison:** CJ uses "model-to-model comparison" as a key workflow step, ensuring the generated code or design is robust and optimized by comparing outputs from different AI models.

## Tools & Resources
- **Claude Code:** The primary AI model used for its "steerable" nature and "intent understanding."
- **Flowy:** CJ Hess's proprietary tool that accepts JSON files to generate structured UI mockups and flowcharts, acting as a structured planning layer for AI-assisted design.
- **Cursor:** An AI-native IDE mentioned in the context of advanced coding workflows.
- **Orcus Conductor:** A platform for complex workflow and process orchestration, designed to handle event-driven, AI-powered cloud-native applications at an enterprise scale.

## Action Items
- [ ] **Develop Structured Prompting Skills:** Stop using free-form text for complex planning. Learn to define system requirements, flowcharts, and data structures using JSON or YAML to provide the AI with a machine-readable "source of truth."
- [ ] **Build a Personal AI Tooling Stack:** Identify a repetitive, multi-step process in your professional life (e.g., onboarding, data cleaning, initial wireframing) and build a small, dedicated tool or set of skills around an LLM to automate it.
- [ ] **Experiment with AI for Onboarding:** Practice using an LLM to handle complex environment setup tasks for a simulated user (e.g., "Help me set up a local environment to run this specific GitHub repo, assuming I have X dependencies").
- [ ] **Explore Workflow Orchestration:** Investigate platforms like Orcus Conductor to understand how to move beyond simple single-prompt tasks and orchestrate complex, multi-step, human-in-the-loop workflows.
