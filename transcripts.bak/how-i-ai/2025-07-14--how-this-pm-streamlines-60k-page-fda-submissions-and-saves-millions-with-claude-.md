# How this PM streamlines 60k-page FDA submissions and saves millions with Claude, Streamlit, and clever AI workflows | Prerna Kaul — How I AI

## Summary
Prerna Kaul, a product leader with extensive experience at companies like Moderna and Amazon Alexa, details how she leveraged Generative AI (specifically Anthropic Claude) to tackle massive regulatory hurdles in the life sciences sector. The core problem addressed was the creation of a Biological License Agreement (BLA)—a highly complex, structured document—for a vaccine treatment that required 4-6 months of effort, nearly 20 specialists, and millions of dollars.

Prerna’s workflow demonstrates how to treat an advanced LLM like a collaborative software engineer and Product Manager. Instead of simply asking the AI for code, she provided the problem statement, the business pitch (focusing on cost savings and impact), and a demo concept. This approach allowed Claude to not only generate functional Python code but also comprehensive setup instructions, component breakdowns, and even a narrative script for running the final demonstration.

The discussion highlights that Generative AI excels at solving highly technical "toil" problems—like complex data structuring (XML-based formats) and sensitive data handling (PHI redaction)—that traditionally require multiple specialized data scientists and engineers to figure out the correct models and implementation methods.

## Key Points
- **De-risking Regulatory Compliance:** The primary value of AI in life sciences is reducing the time, cost, and human resource drain associated with regulatory submissions (e.g., FDA BLA). This accelerates getting life-saving treatments to market.
- **The "PM Prompt" Strategy:** Do not just ask for code; treat the LLM as a highly capable technical partner. Structure your prompt by including: 1) The Problem Statement, 2) The Business Pitch/Impact (Why it matters), and 3) The Desired Demo Outcome. This forces the AI to think like a product team.
- **Structured Data Handling:** For regulated documents that are XML or highly structured, specify this constraint *strictly* in your prompt. Claude was able to successfully structure data into specific formats required by regulatory bodies.
- **PHI Redaction and Safety Alignment:** When dealing with clinical data, the AI must be prompted not only for function but also for compliance. Choosing models known for safety and alignment (like Anthropic) is critical for handling Personally Identifiable Information (PHI).
- **AI as a Technical Architect:** The LLM can act as an architectural guide, providing component names (e.g., "mock data generation," "PHI redaction") and suggesting the correct underlying machine learning models (e.g., for Named Entity Recognition) with minimal domain expertise from the user.

## Tools & Resources
- **Anthropic Claude:** Recommended specifically for its reputation around safety, alignment, and handling complex, structured tasks like PHI redaction in regulated industries.
- **Streamlit:** Used as a deployment framework to quickly turn the generated Python script into an interactive, usable application (a key step for rapid prototyping).
- **CodeRabbit:** An AI code review platform mentioned by the sponsor; useful for engineering teams looking to improve code quality and speed up PR cycles using AI co-pilots.

## Action Items
- [ ] **Develop a Structured Prompt Template:** When using LLMs for complex business processes, adopt the "PM Prompt" structure: Problem Statement + Business Impact/Pitch + Desired Output/Demo.
- [ ] **Master Technical Constraints in Prompts:** If your data is XML-based or requires strict formatting (e.g., JSON schema), explicitly state these structural rules to the AI to ensure compliance and accuracy.
- [ ] **Prototype with Streamlit:** When building an internal tool using Python, use Streamlit for rapid deployment and demonstration. This allows you to quickly move from code output to a functional prototype without needing dedicated frontend development resources.
- [ ] **Focus on "Toil" Reduction:** Identify the most tedious, repetitive, or highly technical parts of your current workflow (e.g., complex regex writing, manual data formatting) and test an LLM solution specifically for eliminating that toil.
