# “Nobody wanted to do this work”: How Emmy Award–winning filmmakers use AI to automate the tedious parts of documentaries — How I AI

## Summary
The episode details how Emmy Award-winning filmmakers use AI not for generating creative content, but for automating the massive, tedious data management challenges inherent in documentary and nonfiction post-production. The guest, Tim McLear, a producer at Ken Burns Florentine Films, explains that the sheer volume of media—which can include tens of thousands of archival photos, hundreds of hours of live footage, and multiple file types—creates a "technical mess" that requires systematic automation.

McLear's approach focuses on using AI as a sophisticated tool to eliminate manual data entry and streamline the workflow. Instead of relying on generic AI descriptions, his team has built custom scripts that prioritize structured data. The key insight is that AI is most effective when it is given explicit guardrails and a "source of truth," such as embedded metadata or web-scraped facts, rather than being asked to guess.

## Key Points
- **The Scale of the Problem:** Documentary production involves immense data ratios. For one series, they gathered 20,000 still images and over 100 hours of footage, requiring a system to make this massive, disparate data set searchable and usable.
- **AI for Toil, Not Just Creation:** The most immediately applicable and impactful use of AI in media is not generating new video, but automating the "toil" of data management and cataloging.
- **The Metadata Imperative:** Generic AI descriptions are insufficient. The breakthrough was integrating structured metadata (GPS data, archival notes, etc.) into the prompt. By treating this metadata as the "source of truth," the AI's output becomes factually grounded and highly specific.
- **Fact-Checking as a Workflow Step:** For journalistic integrity, the process was expanded to include web scraping. This ensures that every piece of data entering the database is verifiable, moving beyond simple visual description to verifiable, external information.
- **The Technical Workflow:** The process involves writing Python scripts that submit media files to advanced LLMs (like Claude 4.5 Sonnet) for analysis, allowing the AI to perform complex tasks like data extraction, categorization, and fact-checking in a repeatable, automated manner.

## Tools & Resources
- **LLMs/APIs:** Anthropic Claude models (specifically Claude 4.5 Sonnet mentioned for its capability) and OpenAI APIs (used for image analysis).
- **Programming:** Python scripting (used to build the automation workflow).
- **Workflow Utility:** Super Whisper (used to clean up messy, off-the-cuff dictation during the coding process).
- **Concept:** Building internal, highly specific "agent" workflows that solve niche, industry-specific pain points.

## Action Items
- [ ] **Systematize Data Ingestion:** Identify the most tedious, repetitive data entry tasks in your current business process (e.g., filing, cataloging, summarizing meeting notes) and build a dedicated, automated workflow around them.
- [ ] **Prioritize Metadata:** When collecting any form of data (research, images, contacts), mandate the capture of structured metadata (dates, sources, location, original file notes) *before* feeding it into an AI prompt. Use this metadata as the primary "source of truth" for the AI.
- [ ] **Learn API Integration:** Focus on learning Python scripting to connect LLM APIs (OpenAI, Anthropic) to your existing data sources. The signal is in the *scripting* that connects the AI to the data, not the prompt itself.
- [ ] **Build a "Fact-Checking" Layer:** For any content that requires high accuracy (reports, articles, presentations), integrate a web-scraping or external database lookup step into your AI workflow to ensure verifiability and guard against hallucination.
