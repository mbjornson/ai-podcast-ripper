# Code with Claude: The 5 biggest updates explained — How I AI

## Summary
This episode of “How I AI” provides a quick overview of five key updates announced at Anthropic’s “Code with Claude” developer event. Claire Vo, a product leader and AI obsessive, walks through the updates, focusing on Claude Code’s routines, Claude Manage Agents’ outcomes and multi-agent framework, the “dreams” memory system, and increased usage limits. The episode emphasizes practical applications and potential use cases, aiming to give listeners a preview of the new features and how they might integrate into their workflows. Vo’s background in product leadership and her enthusiasm for open-source AI (specifically referencing “open claw”) lend credibility to her insights. The episode is tightly focused on actionable information, prioritizing a concise, practical preview over a deep technical dive.

## Key Points
- **Routines:** Claude Code now supports scheduled routines triggered by cron jobs, HTTP requests, or GitHub webhooks. This allows users to automate tasks like weekly newsletter generation or PRD checks. (Specific numbers: 3 trigger types)
- **Outcomes (with Rubrics):** Anthropic’s “Outcomes” feature allows agents to iteratively refine their work based on a defined rubric, essentially “banging its head against the problem” until a desired outcome is achieved. (Specific numbers: up to 20 iterations)
- **Multi-Agent Orchestration:** The API now supports defining teams of agents with an orchestrator and delegates, allowing for complex workflows with specialized roles and toolsets. (Specific numbers: up to 25 agents)
- **Dreams (Agent Memory):** A new primitive for consolidating agent sessions into markdown files for future reference, drawing a parallel to human memory and dreaming. (Specific numbers: not applicable - a conceptual framework)
- **Increased Usage Limits:** Claude Code’s five-hour limits have been doubled across pro max team and seat-based enterprise platforms, and rate limits for Opus models in the API have been increased, addressing a common pain point for developers.

## Tools & Resources
- **Claude Code:** Anthropic’s code generation tool.
- **Claude Manage Agents:** Anthropic’s agentic platform.
- **Open Claw:** Open-source AI project referenced by Claire Vo.
- **GitHub Webhooks & Cron Jobs:** Triggering mechanisms for routines.
- **Markdown Files:** Used for agent memory (Dreams).
