# How to build prototypes that actually look like your product | Colin Matthews (Product leader, AI prototyping instructor at Maven) — How I AI

## Summary
This episode focuses on revolutionizing product prototyping by leveraging AI to bridge the gap between design concepts and functional code, specifically targeting Product Managers (PMs) and non-technical team members. The core discussion centers on how advanced AI tools allow users to convert simple screenshots of existing UIs into structured, reusable component libraries—a process previously requiring expert knowledge in coding or sophisticated design software like Figma.

The guest, Colin Matthews, demonstrates a powerful workflow: using specialized prompts and AI tooling to extract foundational UI elements (like logos, search bars, property cards) from reference images. This creates a modular "component library" that acts as the building block for all subsequent prototypes. The major breakthrough highlighted is not just the speed of prototyping, but the ability to maintain high levels of brand consistency and visual fidelity across multiple ideas, solving a critical adoption hurdle in large organizations where teams resist using non-branded prototype designs.

## Key Points
- **Empowering Non-Coders:** AI tools are "unleashing the product manager," allowing individuals without deep coding skills or advanced Figma expertise to create sophisticated prototypes based on visual input (screenshots).
- **The Component Extraction Workflow:** The process involves feeding the AI a screenshot and using specific prompts designed not just to recreate the view, but specifically to *extract* the underlying components. This turns unstructured images into structured, reusable code assets.
- **Solving Brand Fidelity:** A major pain point in tech adoption is that teams reject prototypes that look like generic third-party products. By building a component library based on actual brand screenshots, PMs can create highly consistent prototypes that feel authentic to the existing product experience.
- **Modular Development (The "Lego" Effect):** The extracted components allow for rapid assembly of entirely new screens or features. Instead of starting from scratch, the AI stitches together pre-approved, branded building blocks, dramatically reducing development errors and ensuring visual consistency across the entire product suite.
- **Enterprise Scalability Note:** While discussing prototyping, a secondary point was raised regarding enterprise tools (like WorkOS), noting that for AI apps to be adopted in large companies, they must address serious security concerns by providing secure authentication, access controls, and audit logs—a massive lift solved by dedicated API layers.

## Tools & Resources
- **AI Prototyping Tools:** Chat-based tools capable of accepting screenshots/images as input and generating structured component code (e.g., V-Zero mentioned in the transcript).
- **Component Libraries:** The foundational concept; a centralized repository of reusable UI elements (buttons, cards, headers) that ensures visual consistency across all product views.
- **WorkOS:** A platform designed to help applications become "enterprise ready" by providing drop-in APIs for complex features like secure authentication and access controls.

## Action Items
- [ ] **Skill Development:** Learn advanced prompt engineering specifically for design/UX workflows. Focus on prompts that instruct AI to *extract* components rather than merely *recreate* views.
- [ ] **Career Move:** Advocate within your team for establishing a formal, centralized "Component Library" (even if initially manual) before starting new feature development to enforce brand consistency and modularity.
- [ ] **Tool Exploration:** Research current AI prototyping tools that accept image/screenshot inputs and output structured code components.
- [ ] **Mindset Shift:** When presenting ideas, shift the focus from "This is a cool new feature" (the idea) to "Here is how this feature integrates into our existing component structure" (the implementation).
